# Mitwirken

Fehler und Funktionswünsche bitte in diesem Fork melden. Ein Fehler der X1C-Anpassungen gehört nicht automatisch in den Issue-Tracker von OrcaSlicer oder Bambu Studio.

Für Änderungen einen Branch von `main` erstellen und einen Pull Request mit Problem, Änderung und Prüfung öffnen. Die Regeln in `AGENTS.md` und gegebenenfalls `tests/AGENTS.md` beachten. Quellcode, Übersetzungen und Profile müssen kompatibel bleiben; Schutzbedingungen dürfen nicht allein zur Aktivierung eines Buttons entfernt werden.

Tests für Transport und X1C-Befehle stehen unter `tools/slicer_linux_runtime/test_*.py`. Erfolgreiche Tests gegen simulierte Geräte ersetzen keine echte Hardwareabnahme. Beobachtete Ergebnisse und Vermutungen bitte klar trennen.

Lizenz- und Autorenvermerke erhalten. Beiträge nur einreichen, wenn sie unter den für die jeweiligen Dateien geltenden Bedingungen weitergegeben werden dürfen. Keine Zugangsdaten, proprietären Netzwerkplugins oder privaten Drucker-/Kontodaten einchecken.
